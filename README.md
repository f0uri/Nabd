# نبض · Nabd

> جديد: [استيراد ملف جلسة Instagram وإعداد التشفير](docs/instagram-session.md).

تطبيق شبكة اجتماعية شبيه بالفيسبوك (أزرق) — يعمل من الراس للراس: **حسابات ودخول + تغذية + نشر بالصور + تفاعلات + تعليقات + أصدقاء + إشعارات + ملف شخصي**، والصور تُخزَّن على **سحابة تلغرام**.

> كل الكود مُختبَر: `tsc` بلا أخطاء · المترو يبني حزمة أندرويد · **14 استعلام GraphQL** مجرّبة على الخادم الحقيقي · رفع صورة → تلغرام → إرجاعها عبر `/media` مجرّب.

### 🔑 الحسابات: كلشي حقيقي، بلا شخصيات تجريبية

التطبيق **كيبان خاوي من أول تشغيل** — ما كاين حتى حساب ولا منشور ولا ستوري مزوّر. كلشي كيتصنع من الناس الحقيقيين:

1. **أنشئ حساب** من الشاشة الأولى: الاسم + البريد + كلمة السر + **صورتك من المعرض** (خطوة اختيارية ولكن مستحسنة).
2. **صوّرتك كتترفع للخادم** (تلغرام) وكتبان فكل بلاصة: منشوراتك، تعليقاتك، الإشعارات، شريط الستوري، والملف.
3. **بدّل صورتك فأي وقت**: اضغط على الصورة فالملف → «صورة الحساب» → اختر صورة جديدة.
4. **زيد صحابك**: بحث بالاسم/البريد → «إضافة صديق»، ومن بعد تغذيتك كتتكوّن من منشوراتهم + منشوراتك.

> **بلا صورة؟** كيبان السيلويت الرمادي الافتراضي (نفس اللي كيدير فيسبوك)، مع **علامة + صغيرة فاسفل الصورة** و«أضف صورة» فرأس الملف. ما كايناش صور جاهزة مدمجة فالتطبيق.

- زر **«إعادة تحميل القائمة»** → تشوف شاشة الانتظار الهيكلية (Skeleton) بنفس هندسة المحتوى.

- `design/styleguide.html` → كل رموز التصميم والمكونات في صفحة واحدة.

## 3️⃣ تشغيل الخادم + تخزين الوسائط على تلغرام

### أ) تشغيل الخادم

```bash
cd server
npm install
npm start          # → http://localhost:4000/graphql  (GraphiQL مفتوح)
```

الحالة: `curl localhost:4000/health`

### ب) ربط سحابة تلغرام ✅ (مضبوط ومُختبَر)

> **عندك دابا:** التوكن والـ chat_id محفوظين فـ `server/.env` (المستثنى من git).
> تجربة حقيقية دُزت: رفع صورة → تلغرام → رجعت من `/media/:id` بنفس البايتات (200 · image/png).

تخزين تلغرام كيخدم بهاد الطريقة: الملف كيترفع للبوت مرة واحدة، وتلغرام كيرجع `file_id` ثابت، وحنا كنحفظو غير `file_id` — وبعدها الخادم كيبث الملف من سيرفرات تلغرام مباشرة (`/media/:id`). يعني ما كتحتاجش مساحة تخزين عندك.

1. افتح **@BotFather** في تلغرام → `/newbot` → خُد **التوكن**.
2. **مهم:** من حسابك صيفط للبوت أي رسالة (مثلاً `/start`). بلا هاد الخطوة تلغرام كيرفض الرفع برسالة `chat not found`.
3. انسخ `.env.example` إلى `.env` واملأ:

```env
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=<الـ ID ديالك>
MEDIA_PROVIDER=telegram
```

4. عاود شغّل الخادم. غادي تشوف: `📦 media storage → telegram`.

**اختبار سريع للرفع والعرض** (من GraphiQL أو curl):

```bash
curl localhost:4000/graphql \
  -F 'operations={"query":"mutation($f: File){ createPost(text:\"تجربة\", file:$f){ id media{ uri } } }","variables":{"f":null}}' \
  -F 'map={"f":["variables.f"]}' \
  -F 'f=@/path/to/photo.jpg;type=image/jpeg'
# النتيجة: { "createPost": { "media": { "uri": "/media/m_xxxxxxxx" } } }
# افتح http://localhost:4000/media/m_xxxxxxxx → الصورة
```

### ⚠️ حدود تلغرام اللي خاصك تعرفها (مهمة قبل الإنتاج)

| القيد | القيمة | الأثر |
|---|---|---|
| أقصى حجم رفع للبوت | 50 ميغابايت | فيديوهات أكبر ما غاديش ترفع |
| أقصى حجم تنزيل عبر `getFile` | 20 ميغابايت | ملفات أكبر ما غاديش تتعرض عبر البروكسي |
| `file_id` | صالح ما دام الملف فمحادثة البوت | إلا حذدتي المحادثة/الملف، ضاع الوسيط |

**الحلول:** تشغيل **Local Bot API Server** (يرفع الحد لـ 2000 ميغابايت)، أو للفيديو الثقيل استعمل **S3 + CloudFront + HLS** زي ما في خطتك (المرحلة 4). الكود مقسّم بـ `src/storage/` حتى تبدّل المزوّد بسطر واحد في `.env`.

**أمان:** التوكن كيبقى غير على الخادم — عمره ما يدخل لتطبيق الموبايل. لا تعاود تصيفط الـ ID ديالك فمكان عام.

### 🔌 الربط بالخادم (منجز)

الواجهة دابا كتخدم مع **الخادم الحقيقي** أو مع بيانات محلية، حسب متغيّر واحد:

```bash
cd mobile
cp .env.example .env
# بدّل العنوان بـ IP ديال الكمبيوتر (ماشي localhost — التيليفون ماشي هو الكمبيوتر)
EXPO_PUBLIC_API_URL=http://192.168.1.10:4000/graphql
EXPO_PUBLIC_DATA_SOURCE=auto
npx expo start -c      # -c كيمسح الكاش باش يقرا .env الجديد
```

| الوضع | السلوك |
|---|---|
| `graphql` | يشتغل على الخادم فقط (يرمي خطأ إذا كان مغلقاً) |
| `mock` | بيانات محلية فقط (بلا خادم) — فيها تأخير 750ms وفشل عشوائي 6% لاختبار الحالات |
| `auto` (افتراضي) | كيفحص الخادم مرة واحدة، وإلا ما جاوبش كيرجع للبيانات المحلية بلا ما يحبس التطبيق |

في آخر الـ feed كاينة **شريحة** كتوري من أين كتجي البيانات («خادم GraphQL» / «بيانات محلية») وزر **«إعادة فحص الخادم»**. وإذا سقط الخادم فوسط الاستعمال، التطبيق كيرجع للبيانات المحلية تلقائياً بدل ما يبان فارغ.

> ملاحظة: التعليقات المكتوبة على الخادم كتترجع بـ `id` حقيقي من الخادم وكتبدل التعليق المؤقت — يعني الحذف كيخدم على السيرفر مزيان.

### 📝 شاشة إنشاء منشور + رفع الصور لتلغرام (منجزة)

`FeedScreen` → اضغط على «فيمَ تفكر، يوسف؟» → كتب النص، اختار الصورة من المعرض أو الكاميرا، اختار الخصوصية (عامة/أصدقاء/أنا فقط) → **نشر**.

السيناريو الكامل:
```
تيليفون → FormData (GraphQL multipart) → الخادم → sendDocument → تلغرام (file_id)
                                                        ↓
التطبيق كيبان فيه المنشور فوراً (Optimistic) ← رابط البث /media/:id
```
- المنشور كيبان فوراً فالقائمة حتى قبل ما يجاوب الخادم، وإذا فشل الرفع **كيختفي** مع رسالة خطأ (بلا ما يبقى منشور وهمي).
- الحد الأقصى للرفع 50MB (قيد تلغرام)؛ الصور كتضغط بـ `quality: 0.85` قبل الرفع.
- إذا كنت فـ `mock` mode، الصورة كتبقى محلية فالتيليفون بلا رفع.

### 👥 الحسابات · الأصدقاء · الإشعارات · الملف الشخصي (منجزة)

| الميزة | التفاصيل |
|---|---|
| **تسجيل ودخول** | `register` / `login` بكلمة سر مشفّرة (scrypt) وتوكن **JWT (HS256)** صالح 30 يوماً، محفوظ فـ AsyncStorage وكيتسترجع عند فتح التطبيق. |
| **حماية الخادم** | كل mutation حساسة كترفض بلا توكن (`UNAUTHENTICATED`)؛ الجلسة كتتقري من هيدر `Authorization: Bearer`. |
| **أصدقاء** | شاشة بحث + «أصدقائي» + «أشخاص قد تعرفهم» (خوارزمية: أصدقاء الأصدقاء أولاً) + إضافة/إلغاء بتحديث فوري. |
| **إشعارات** | كتتولّد تلقائياً عند التفاعل/التعليق/المتابعة، مع عدّاد غير المقروء وتعليم الكل كمقروء. |
| **ملف شخصي (v2)** | نفس ترتيب فيسبوك: **غلاف** أزرق كبير + **صورة رمزية متراكبة** بحلقة بيضاء + الاسم مع شارة التوثيق + سطر (عدد الأصدقاء · المنشورات) + النبذة + 3 أزرار (تعديل الملف · ستوري · خروج) + **4 تبويبات**: المنشورات · حول · الأصدقاء · الصور، مع مؤشّر أزرق تحت التبويب النشط. |
| **تبويب «حول»** | صفوف معلومات بأيقونات رفيعة: المدينة · البريد · الأصدقاء · عضو منذ. |
| **تبويب «الأصدقاء»** | قائمة كاملة + Skeleton أثناء التحميل + حالة فارغة. |
| **تبويب «الصور»** | شبكة 3 أعمدة بنسبة 1:1 لكل صورة منشورة. |
| **تعديل الملف** | Bottom sheet (مقبض + **صورة الحساب (رفع من المعرض)** + حقل الاسم + نبذة 160 حرف مع عدّاد + حفظ/إلغاء) بتحديث فوري بلا إعادة تحميل. |
| **تغذية شخصية** | منشوراتي + منشورات أصدقائي + العامة؛ منشورات «الأصدقاء فقط» ما كتبانش لغير الأصدقاء. |

### 💬 التعليقات · الستوري · الصور الرمزية الحقيقية (جديدة)

| الميزة | التفاصيل |
|---|---|
| **صور الحسابات (حقيقية 100%)** | **التطبيق ما فيهاش حتى صورة:** لا مولّدة لا مدمجة. صاحب الحساب هو اللي كيرفع صورتو من المعرض (`register(file: …)` فالتسجيل، ولا `updateProfile(file: …)` فأي وقت) → الخادم كيخزّنها (تلغرام) وكيرجّع `avatarUrl` (`/media/xxx`). |
| **بلا صورة = بحال فيسبوك** | كيفيسبوك، الحساب اللي ما عندوش صورة كيبان بـ **سيلويت رمادي افتراضي** (دائرة `#E7EAEE` + رأس وأكتاف `#BEC2C6`) — بلا حروف وبلا صور مزوّرة. وفرأس الملف ديالك كاين **علامة + صغيرة داخل الصورة من الأسفل** + «أضف صورة» (نفس مكان زر الإضافة ففيسبوك). |
| **شاشة التعليقات** | `CommentsSheet` — Bottom sheet بحال فيسبوك: معاينة المنشور · قائمة التعليقات · إعجاب على كل تعليق (Optimistic + تراجع) · حذف تعليقك · حقل الكتابة كيطلع فوق الكيبورد. |
| **عداد التعليقات** | بطاقة المنشور كتعرض آخر تعليقين + «عرض كل التعليقات (N)»، والضغط على «تعليق» ولا على الحقل كيفتح نفس الشاشة. |
| **إعجاب التعليقات فالخادم** | mutation جديدة `likeComment(postId, commentId)` كترجّع `{ likes, likedByMe }` وكل مستخدم عندو إعجاب مستقل (`likedBy[]`). |
| **الستوري** | `StoryTray` + `StoryViewer`: أشرطة تقدّم 5 ثوان، تنقّل باللمس يمين/يسار، تعليم كمقروء، ورد سريع. «أنشئ ستوري» كتفتح المعرض وكتزيد ستوري بالصورة (محفوظة فـ AsyncStorage)، وإلا ستوري نصي. |
| **زر الستوري فالملف** | نفس المسار: صورة من المعرض → ستوري كتبان مباشرة فالصفحة الرئيسية. |

### 💬 الرسائل / Messenger (جديدة — المرحلة 5 بدات)

دردشة حقيقية بين الحسابات، محفوظة فقاعدة البيانات، وبتحديث تلقائي مؤقت (polling 4 ثواني) حتى نربطو WebSockets.

| الميزة | التفاصيل |
|---|---|
| **محادثة وحدة لكل زوج** | جدول `conversations` بـ `check(user_a < user_b)` + `unique` → مستحيل تصير جوج محادثات بين نفس الجوج، حتى إلا ضغطو بجوج فنفس اللحظة. |
| **فتح المحادثة من الأصدقاء** | فـ شاشة «الأصدقاء»، كل صديق عندو زر دائري فيه أيقونة `chatbubble-outline` → كيتفتح Messenger وكتتصنع المحادثة (`startConversation`) وكتمشي مباشرة للرسائل. |
| **أيقونة الرسائل فالشريط العلوي** | فـ **كل** الشاشات (الرئيسية · الأصدقاء · الإشعارات · الملف) — والشارة الحمراء كتعرض **عدد الرسائل غير المقروءة الحقيقي** (`unreadMessagesCount`)، كتتحدّث كل 15 ثانية. |
| **قائمة المحادثات** | بحث فالمحادثات (كيتم فـ الخادم `ilike`) · معاينة آخر رسالة («أنت: …» إلا كانت منك) · الوقت · شارة غير المقروء · سحب للتحديث · Skeleton أثناء التحميل · حالة فارغة كتشرح كيفاش تبدا. |
| **شاشة المحادثة** | فقاعات بحال Messenger (رسائلك زرقاء على اليمين، اللي جات على اليسار) · **علامات القراءة** (`checkmark` / `checkmark-done`) · حقل كتابة كيطلع مع الكيبورد · إرسال بـ Enter ولا بالزر. |
| **إرسال متفائل (Optimistic)** | الرسالة كتبار فوراً بـ id مؤقت `tmp_*`، ومن بعد كتبدّل بالنسخة الحقيقية من الخادم. إلا فشل الإرسال → كتحيّد بوحدها + Toast بالخطأ. |
| **إشعارات الرسائل** | كل رسالة جديدة كتزيد إشعار `type: "message"` («رسالة: «…»») فـ شاشة الإشعارات، والشارة ديالها كتتحدّث. |
| **الخصوصية** | كل query/mutation ديال الرسائل كتتحقق من العضوية (`FORBIDDEN` إلا ماشي طرف فالمحادثة) — حتى الاشتراك `messageAdded` كيتفحّص. |

**الـ API الجديد (GraphQL):**
```graphql

type MessagePage { messages: [Message!]! nextCursor: String }

Mutation:     startConversation(userId) · sendMessage(conversationId, text) · markConversationRead(conversationId)

```

### ⚡ الدردشة اللحظية + الضغطة المطوّلة (جديدة)

**كل شي كيوصل فوراً** — بلا ما تسد الشاشة ولا تعاود تحمّل. القناة: **WebSocket** مدمج فـ React Native (بلا مكتبة زايدة)، والخادم فيه `ws` على `/ws`.

| الميزة | التفاصيل |
|---|---|
| **توصيل لحظي** | الرسالة كتخرج من المرسل وكتوصل للطرف الآخر فـ **~10 ملي ثانية** (مقاس فاختبار حقيقي: 9ms). نفس القناة كتنقل: التعديل · الحذف · التفاعل · القراءة · «يكتب الآن…». |
| **إعادة اتصال تلقائية** | إلا طاح الإنترنت ولا توقف الخادم: التطبيق كيعاود يتصل بتراجع تدريجي (1s → 2s → 4s … 15s) وكيعاود يشترك فالمحادثات المفتوحة. وفوق هادشي كاين **polling احتياطي كل 8 ثواني** إلا ماكانش WebSocket. |
| **مؤشر الحالة** | فرأس المحادثة: نقطة خضراء + «متصل · لحظي» (ولا «اتصال عادي» إلا طاح) + «فلان كيكتب…». |
| **الضغطة المطوّلة** | ضغطة مطوّلة على أي رسالة كتفتح قائمة سفلية فيها: **شريط التفاعلات** · رد · تعديل · ترجمة · حذف. |
| **رد** | الرسالة المردود عليها كتظهر فوق النص داخل الفقاعة، وفوق حقل الكتابة كيبان شريط «رد على…» بالغاء. الخادم كيرفض الرد على رسالة محذوفة ولا على رسالة من محادثة أخرى. |
| **تعديل** | غير صاحب الرسالة. كتكتب النص الجديد فنفس الحقل (كيولي مميّز بالأزرق)، وكيبان «عُدِّلت» تحت الرسالة عند الجوج. متفائل + تراجع تلقائي. |
| **حذف** | حذف ناعم (tombstone): كتتبدّل بـ «تم حذف هذه الرسالة» عند الجوج، وكتتحيّد تفاعلاتها. الردود القديمة عليها ما كتبقاش معلّقة. متفائل + تراجع. |
| **تفاعل** | 6 تفاعلات بأيقونات متجهة (بلا إيموجي): إعجاب · حب · ضحك · اندهاش · حزن · غضب — كيتبانو فقرص صغير تحت الفقاعة بالعدد. تفاعل واحد لكل مستخدم (نفس التفاعل كيحيدو). |
| **ترجمة** | عربية · فرنسية · إنجليزية. كتظهر فمربع تحت الرسالة باللغة المختارة، وكتقدر تخفيها. الخادم كيخزّن الترجمة فذاكرة مؤقتة (نفس النص ما كيتطلبش مرتين). سلسلة مزوّدين: `TRANSLATE_URL` (LibreTranslate) → Google gtx → MyMemory. |
| **قراءة** | ✔ / ✔✔ على رسائلك. كتتبدّل لحظياً ملي الطرف الآخر كيحل المحادثة (بلا polling). |

| **منتقي التفاعلات** | ضغطة مطوّلة على «أعجبني» ف أي منشور → بار فيه **6 تفاعلات** (إعجاب · حب · هاها · واو · حزن · غضب) بأيقونات متجهة ملوّنة، والزر كيتبدّل لاسم التفاعل المختار. متفائل + تراجع. |

| **صور فالدردشة** | زر الصورة حد حقل الكتابة → من المعرض → كتظهر فوراً (Optimistic) وكتترفع لتلغرام، والطرف الآخر كيشوفها لحظياً. |
| **إشعارات لحظية** | أي إشعار جديد (رسالة · إعجاب · تعليق · صداقة) كيوصل عبر WebSocket: شارة الإشعارات فالأسفل وفالشريط العلوي كتزيد فوراً، وToast ملي تكون رسالة وماشي فالمحادثة. |
| **الإشعارات كتفتح بلاصتها** | إشعار رسالة → كتفتح المحادثة مع الشخص · إشعار تفاعل/تعليق → كتفتح شاشة تعليقات داك المنشور. |

| **بلا أدوات ديمو** | تحيّدت لوحة «أدوات تجريبية» من الفيد، و«فيمَ تفكر، يوسف؟» ولّات كتخاطبك **باسمك الحقيقي**، وحتى زر بحث فالشريط العلوي ولّا كيخدم (كيفتح تبويب البحث). |

### 🎬 الريلز + شريط تنقل جديد (جديدة)

**شريط التنقل تعاود تصميمو** باش يبان كتطبيق كبير، ماشي ديمو:

| البلاصة | قبل | دابا |
|---|---|---|
| الشريط العلوي | بحث + رسائل + **إشعارات** | **بحث + رسائل فقط** (أيقونتين حد بعضهم — الإشعارات تحيدت من الفوق) |
| الشريط السفلي | 6 تبويبات **بالكتابة** تحتها | **5 أيقونات بلا حتى كلمة**: رئيسية · أصدقاء · **ريلز** · إشعارات · قائمة |
| البحث | تبويب فالقاع | كيتفتح من **أيقونة البحث** اللي فوق |
| الإشعارات | أيقونة فوق + شارة | أيقونة فالقاع + **شارة حقيقية لحظية** (99+) |

الشريط السفلي ولا أيقونات بحال التطبيقات العالمية: الأيقونة النشطة كتولّي **معمورة** + لون البراند + خط صغير تحتها (18×2.5px)، وباقي الأيقونات رمادية. `accessibilityRole="tab"` و`accessibilityLabel` بالعربية لكل واحدة، ودعم كامل لـ RTL والـ safe-area.

**الريلز (فيديوهات عمودية بحال إنستغرام):**

| التفاصيل | كيفاش |
|---|---|
| **سكرول كامل الشاشة** | قائمة عمودية `pagingEnabled` + `snapToInterval` = ارتفاع الشاشة → كل سحب = ريل وحد، بلا ما يوقف نص الطريق |
| **تشغيل تلقائي** | غير الريل **النشيط** اللي كيتشغّل (اللي بلاصتو فالشاشة)، اللي قبل واللي من بعد كيتوقّفو — توفير للبطارية والداتا |
| **الصوت** | مسدود افتراضياً (بحال إنستغرام)، وزر `volume` فوق كيتحكّم فيه |
| **التحكم** | ضغطة على الفيديو = وقفة/تشغيل + شارة `play` · شريط تقدم فوق كيتبع الوقت الفعلي |
| **الإجراءات** | حب · تعليقات · إعجاب · **عدد المشاهدات** · وحذف إلا كان الريل ديالك |
| **المشاهدات** | `viewReel(postId)` كتسجل مشاهدة **مرة واحدة لكل مستخدم** (جدول `reel_views` فـ PostgreSQL) |
| **الرفع** | زر `+` فوق → المعرض → فيديو → وصف اختياري → رفع multipart لتلغرام → كيبان فوراً فالأعلى |
| **الحدود** | **60 ثانية / 18MB** — الحد مقصود حيت تلغرام Bot API كيحد التنزيل فـ 20MB، والخادم كيرفض بـ`VIDEO_TOO_LARGE` |
| **بث الفيديو** | `/media/:id` ولّى كيدعم **HTTP Range (206)** — ضروري باش المشغل يقدر يقدّم ويرجّع فالفيديو بلا ما يعاود يحمّلو كامل. تلغرام ما كيدعمش Range → كيتحمّل وكيتقسّم (الفيديوهات صغار) |
| **الفيد العادي** | الفيديوهات ما كتختلطش مع الصور فالفيد — كل فيديو بلاصتو فالريلز. إلا ظهر فيديو فالبحث/الملف كيبان كبطاقة بـ`play` وكتودّيك للريلز |

### 📥 ريلز إنستغرام كتتجاب **أوتوماتيكياً** (جديدة)

ما كاين حتى زر، حتى رابط، وحتى تدخل من المستخدم: **الخادم كيجيب الريلز بوحدو** وكتطيح مباشرة فتبويب «ريلز» — والتطبيق كيتحدّث بوحدو.

**كيفاش كيدور (كل `IG_INTERVAL_MINUTES`، افتراضياً 45 دقيقة):**

```
1) اكتشاف   →  حسابات عامة (web_profile_info) + بحث عمومي (site:instagram.com/reel <موضوع>)
                + Graph API الرسمي (إلا كان توكن) + لائحة احتياطية data/ig-catalog.json
2) طابور    →  كل كود كيتسجل فـ ig_queue (بلا تكرار · محاولات · backoff)
3) معالجة   →  قراءة الريل → تحميل الـ MP4 → تخزين عندنا (mirror) → نشر باسم «ريلز نبض»
4) تكرار    →  دورة جديدة كل 45د · الريلز الجداد كيبانو فالتطبيق بلا ما يعاود يحلّ
```

| التفصيل | كيفاش |
|---|---|
| **صفر إعداد** | قوائم الحسابات (15) والمواضيع (12) **مدمجة فالكود** — كتخدم أوتوماتيكياً من أول تشغيل، بلا ما تحط حتى اسم حساب. `.env` غير إلا بغيتي تبدّلهم |
| **التناوب** | كل دورة كتاخد 3 حسابات + 4 مواضيع بالتناوب، وكيتعلم الحسابات من الريلز اللي جاب (الاكتشاف كيكبر بوحدو) |
| **كيضمان البلاصة** | إلا كان عدد الريلز أقل من 8 (`IG_KEEP_MIN`) كيزيد فالدورة باش التبويب ما يبقاش خاوي |
| **حساب النشر** | كيتصنع حساب `reels@nabd.app` باسم **«ريلز نبض»** (verified) مرة واحدة، وكل الريلز المستوردة كتتنشر منّو مع شارة `source=instagram` |
| **الإسناد** | شارة **«من إنستغرام · @الحساب»** فوق الوصف، والضغط عليها كيحلّ الريل الأصلي |
| **بلا تكرار** | `source_url` unique + `ig_queue(shortcode)` primary key |
| **بلا حرق للحساب** | 429 من إنستغرام → الحساب كيتريّح ساعة · الأخطاء المؤقتة كتبقى فالطابور حتى 3 محاولات · النهائية (`REEL_TOO_LONG`, `NOT_A_VIDEO`…) كتتخطى |
| **التخزين** | كيتحمّل وكيتخزّن **محلياً** (mirror) حيت روابط CDN كتموت · البث بـ`Range 206` · حد `IG_MAX_MB` (18MB) لكل ريل |
| **التطبيق** | ترويسة «ريلز» فيها مؤشر **جلب تلقائي** (نقطة خضراء = شغّال / صفراء = كيجيب دابا)، والسكرول كيتحدّث بوحدو ملي كيوصلو ريلز جداد |
| **تنظيف** | `npm run prune:reels -- --max-mb 12 --keep 5` كيحيد الثقيل والقديم من الرصيد |

**🔐 لوحة الأدمن داخل التطبيق (بلاصة وحدة لكلشي — بلا ما تمس حتى ملف):**

من التطبيق: **القائمة ← الإدارة ← لوحة الأدمن** (كتبان غير للحساب اللي عندو `isAdmin`). فيها كلشي فبلاصة وحدة:

| فـ اللوحة | شنو كيدير |
|---|---|
| **بطاقة الحالة** | واش الكوكيز محفوظة · آخر 4 حروف من `sessionid` (بصمة بلا ما تبان الكوكيز) · مصدرها (`admin` / `.env`) · وقت الحفظ · عدد الريلز · عدد اللي فالطابور · الدورة كل شحال |
| **خانة الكوكيز + «حفظ واختبار»** | تلصق `sessionid=…; csrftoken=…; ds_user_id=…` (ولا غير `sessionid` بوحدو) → كتتحقق، كتتحفظ فقاعدة البيانات، وكتبدا **دابا** دورة جلب بلا ما تعاود تشغّل الخادم |
| **نتايج الاختبار** | كل قناة بوحدها: الفيد الرئيسي · ريلز (clips) · هاشتاغ · بروفايل — وواش خدامة وشحال فيديو لقّات (404/429 كتبان بالعربية) |
| **«جلب الريلز دابا»** | تشغيل دورة فورية بلا ما تنتظر 45 دقيقة |
| **«حذف الكوكيز»** | كتمسح الجلسة من قاعدة البيانات وكترجع للحالة بلا تسجيل دخول |

> الكوكيز كتتخزن فـ `app_settings.ig_session` **فقاعدة البيانات**، وكتتقرى فكل دورة — وحتى مرة ما كتتوصل للتطبيق (`fingerprint` غير 4 حروف). أول مستخدم فقاعدة البيانات كيتولّى أدمن أوتوماتيكياً (`isAdmin`) إلا ما كان حتى أدمن.
>
> ⚠️ استعمل حساب إنستغرام جديد (ماشي الأساسي). الكوكيز كتموت منين تدوز تسجيل الخروج من إنستغرام — غير عاود لصقها فاللوحة.

### 🗄️ قاعدة البيانات: PostgreSQL (المرحلة 3 — منجزة)

كل شي دابا محفوظ فـ **PostgreSQL** (10 جداول) — إعادة تشغيل الخادم ما كتمسح والو، حتى الرسائل.

| الجدول | فيه |
|---|---|
| `users` | الحسابات الحقيقية (كلمة السر scrypt) + `avatar_media_id` (الصورة اللي رفعها صاحبها) |
| `friendships` | الصداقات (علاقة متبادلة، مفتاح `(user_a, user_b)` بترتيب أبجدي) |
| `posts` | المنشورات + الخصوصية (`public/friends/private`) + `media_id` |
| `reactions` | تفاعل واحد لكل مستخدم لكل منشور `(post_id, user_id)` |
| `comments` · `comment_likes` | التعليقات وإعجاباتها |
| `notifications` | إشعارات كل مستخدم + `read` |
| `media` | ربط `file_id` ديال تلغرام بالوسيط (باش الروابط تبقى دايمة بعد الـ restart) |
| `conversations` | محادثات Messenger — وحدة لكل زوج مستخدمين + `last_at` للترتيب |
| `messages` | الرسائل + `read_at` · `edited_at` · `deleted_at` · `reply_to_id` |
| `message_reactions` | تفاعلات الرسائل (واحد لكل مستخدم لكل رسالة) |

**كيفاش كيخدم:**
- الخادم كيشوف `DATABASE_URL`. إلا كان موجود → كيتصل بـ PostgreSQL حقيقي (`pg` pool).
- إلا ماكانش → كيستعمل **PGlite** = نفس PostgreSQL (18.6) مُصرَّف لـ WebAssembly، كيخزّن الملفات فـ`server/data/pg`. بلا تنصيب، وبنفس SQL بالضبط.
- عند الإقلاع: `schema.sql` كيتنفّذ (`IF NOT EXISTS`)، من بعد كيتمدّ الكاش ديال المستخدمين/الصداقات/عدد المنشورات (باش `publicUser` يبقى سريع).
- الاستعلامات كلها parameterized (`$1, $2 …`) — بلا حقن SQL. المنشورات كتتجاب فـ 3 استعلامات غير (بلا N+1): المنشور + التفاعلات + التعليقات.

**للانتقال لسيرفر حقيقي:**
```bash
# 1) سيرفر PostgreSQL (ولا docker compose up -d postgres)
# 2) فـ server/.env
DATABASE_URL=postgres://nabd:nabd@localhost:5432/nabd
# 3) عاود شعل الخادم — المخطط كيتصنع بوحدو
```

**اللي بقا فالذاكرة:** الكاش (كيتعاود يتحمّل عند الإقلاع) و pubsub ديال الاشتراكات (خاصو Redis فـ المرحلة 5). الوسائط نفسها على تلغرام.

## 7️⃣ قرارات تقنية — وعلاش

- **Zustand بدل Redux**: أقل كود وأسرع (بلا Provider ولا boilerplate)، وكافي لتطبيق من هاد النوع. الـ store واحد = «مصدر حقيقة واحد» لكل الشاشات.
- **FlashList بدل FlatList**: إعادة استعمال الخلايا (recycling) بدل إنشاء عناصر جديدة → ذاكرة أقل بكتير مع آلاف المنشورات.
- **Skeleton بلون + geometry حقيقي**: يمنع «قفزة التخطيط» (layout shift) ويحسّس التطبيق بالسرعة.
- **ظل واحد فقط + فصل بالخلفية**: أداء أعلى على أندرويد الضعيف، وواجهة أنظف.
- **GraphQL**: طلب الحقول المحددة فقط → بيانات أقل على باقة المستخدم (مهم فالمغرب).
- **Tokens في مكان واحد**: تغيير اللون أو المسافة كيوقع فكل الشاشات بلا لمس أي شاشة.
