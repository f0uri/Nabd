# ربط ملف جلسة Instagram

الميزة موجودة في **القائمة ← الإدارة ← لوحة الأدمن ← اختيار ملف الجلسة**. بعد اختيار الملف، اضغط **حفظ واختبار**. لا يُرفع الملف تلقائيًا عند اختياره، ولا يُعرض محتواه في الشاشة. الحفظ والاختبار والحذف والجلب اليدوي محمية بصلاحية الأدمن في الخادم، وليس بإخفاء الأزرار فقط.

## إعداد الخادم

1. اضبط `AUTH_SECRET` عشوائيًا وانشر الخادم عبر **HTTPS**؛ الجلسة بيانات دخول حساسة.
2. ولّد مفتاح تشفير على الخادم، ولا ترسله في المحادثة:

   ```sh
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```

3. ضع الناتج في `IG_SESSION_ENCRYPTION_KEY` في متغيرات الاستضافة أو `server/.env`. لا تضفه إلى GitHub. حافظ على المفتاح نفسه بين إعادات التشغيل، واحفظه منفصلًا عن نسخة قاعدة البيانات. فقدانه أو تغييره يتطلب استيراد الجلسة من جديد.
4. ابنِ نسخة APK جديدة؛ أضيفت وحدة Expo Document Picker إلى التطبيق. النسخ المثبتة سابقًا لن تحتوي زر الاستيراد.
5. سجّل الدخول إلى نبض بحساب أدمن، واختر الملف ثم احفظه واختبره.

لا يطلب التطبيق كلمة مرور Instagram، ولا يقوم بتسجيل الدخول أو تجاوز التحقق الثنائي. استخدم جلسة حساب تملكه، ولا تشارك ملفها مع أي شخص.

## الصيغ المدعومة

الحد الأقصى **64 كيلوبايت**، والامتدادات: `.json` و`.txt` و`.cookies` و`.session`. الامتداد وحده لا يكفي؛ يتحقق الخادم من المحتوى.

- JSON: مصفوفة كوكيز من المتصفح أو كائن يحتوي `cookies` كمصفوفة. عند وجود `domain` يجب أن يكون `instagram.com` أو نطاقًا فرعيًا صحيحًا له.
- JSON: خريطة كوكيز في `cookies` أو حقول `sessionid` و`csrftoken` و`ds_user_id` مباشرة.
- JSON: كائن `authorization_data` يحتوي `sessionid` (مثل بعض ملفات إعدادات عملاء Instagram).
- JSON: حقول `sessionId` و`csrfToken` و`dsUserId` للتوافق مع إعدادات نبض السابقة.
- Netscape `cookies.txt`، بما في ذلك سطور `#HttpOnly_`.
- ما زال لصق ترويسة الكوكيز أو قيمة sessionid وحدها مدعومًا.

ملفات pickle أو الجلسات الثنائية غير مدعومة ولا يتم تنفيذها. الملفات بدون sessionid غير صالحة. تُرفض كوكيز الجلسة المنتهية عند توفر تاريخ انتهائها، والتصديرات الغامضة التي تتضمن جلسات متعددة مختلفة. لا تضف ملفات الحسابات الحقيقية إلى الاختبارات.

## الحفظ والأمان

- يستخرج الخادم **ثلاثة حقول فقط**، ويتجاهل كلمة المرور وبيانات الجهاز وأي حقول إضافية.
- يُخزن السجل في `app_settings.ig_session` مشفرًا بـ AES-256-GCM مع nonce جديد. لا يوجد رجوع إلى التخزين النصي عند غياب مفتاح التشفير.
- تُرحّل سجلات الجلسة النصية القديمة إلى التشفير عند تحميلها مع مفتاح صالح. عند غياب المفتاح أو تلف السجل، لا تُستخدم الجلسة المحفوظة. النسخ الاحتياطية القديمة قد تظل تحتوي السجل النصي وتحتاج معالجة من مسؤول الاستضافة.
- تُحذف نسخة الملف المؤقتة التي ينشئها منتقي الملفات بعد قراءتها. الملف الأصلي يبقى في جهاز المسؤول؛ يمكن حذفه يدويًا بعد الاستيراد. المسودة تبقى في ذاكرة الشاشة حتى الحفظ أو الإزالة أو مغادرة الشاشة، ولا تُخزن في AsyncStorage.
- لا تُعاد الكوكيز من GraphQL. يعرض الخادم الحالة وآخر أربعة أحرف للتعرف على الجلسة فقط.
- الطلبات التي تستخدم الجلسة لها مهلة، ولا تتبع تحويلات HTTP. توقف الجلسة عند 401/403 أو تحويل تسجيل الدخول أو challenge/checkpoint أو 429، ولا تحاول تجاوز التحقق. يبقى الإيقاف في ذاكرة الخادم حتى إعادة الاستيراد الصريح أو إعادة تشغيل الخادم. إعادة تحميل السجل في دورة خلفية لا تلغي الإيقاف.
- تحقق الحساب يستخدم endpoint يتطلب تسجيل الدخول، وليس مجرد نجاح قراءة بروفايل عام. عدم وجود فيديوهات في feed لا يعني أن الجلسة غير صالحة.

## علاقتها بالريلز

يستخدم التكامل الحالي الجلسة في اكتشاف الريلز من القنوات المتاحة، ثم يمرر الأكواد إلى طابور الاستيراد الموجود. أُصلح خطأ كان يستخدم `topics` قبل تعريفه، وخطأ شكل بيانات القنوات الذي كان يعطّل عرض حالة الأدمن بعد الاكتشاف.

`IG_AUTO_IMPORT=1` يشغّل دورة تلقائية بعد التحقق الناجح، ثم الدورات المجدولة بحدودها الحالية. مع `IG_AUTO_IMPORT=0` يتم حفظ الجلسة واختبارها **دون** بدء دورة تلقائية؛ يمكن للأدمن طلب الجلب يدويًا.

هذا **ليس API رسميًا من Meta**، ولا يضمن استنساخ صفحة «مقترح لك» أو استمرار عمل endpoints الداخلية. قد يُقيّد Instagram الحساب أو الخادم. الجلسة لا تمنح إذنًا لإعادة نشر المحتوى: استورد فقط ما تملكه أو لديك إذن لاستخدامه، وفضّل التكامل الرسمي حيث يتوفر. مسار تنزيل واستضافة الوسائط الموجود سابقًا لم يُستبدل بتضمين رسمي في هذا التغيير.

## التحقق

```sh
cd server
npm ci
npm run test:ig-session
```

اختبارات parsing والتشفير والصلاحيات تستخدم بيانات مصطنعة، واختبار الحفظ والاسترجاع والحذف يعمل على PGlite معزول في مجلد مؤقت وطلبات Instagram محاكاة، دون لمس قاعدة الاستضافة أو إرسال أسرار إلى Instagram.

```sh
cd mobile
npm ci
npm run typecheck
npx expo export --platform android
```

لم تُجر تجربة بحساب حقيقي أو اختبار منتقي الملفات على هاتف فعلي في بيئة التطوير هذه؛ الاتصال الخارجي بـ Instagram غير متاح فيها.
